تم تجهيز المشروع للبناء على خادم Windows عبر GitHub Actions.

مهم: لا يمكن إنشاء حساب GitHub أو رفع المشروع إلى حسابك نيابةً عنك دون تسجيل دخولك وموافقتك. لا ترسل كلمة مرورك أو رموز التحقق هنا.

خطوات مرة واحدة:
1- أنشئ حسابًا مجانيًا من https://github.com/join باستخدام بريدك.
2- بعد تسجيل الدخول افتح https://github.com/new وأنشئ مستودعًا جديدًا باسم data-entry-training-platform واختر Private.
3- من صفحة المستودع اختر Add file ثم Upload files.
4- فك ضغط هذه الحزمة، وافتح المجلد الداخلي الذي يحتوي package.json وmain.js وindex.html، ثم ارفع محتويات هذا المجلد كلها (بما فيها مجلد .github) إلى المستودع.
5- اضغط Commit changes.
6- افتح تبويب Actions، واختر Build Windows installer، ثم Run workflow.
7- انتظر حتى يصبح التشغيل أخضر. افتح التشغيل ثم قسم Artifacts ونزّل Platform-Windows-x64-Setup.
8- فك ضغط ملف Artifact وستجد ملف Setup.exe.

ماذا يفعل البناء؟
- يبني نسخة Windows x64 على خادم Windows لدى GitHub.
- يضم Electron وملفات التطبيق داخل مثبت NSIS.
- جهاز تثبيت البرنامج لا يحتاج Node.js أو npm أو الإنترنت أثناء التثبيت.

تنبيه: ملف Setup.exe لم يُبنَ بعد؛ هذه الحزمة تتضمن إعداد البناء الآلي. يلزم رفعها إلى مستودع GitHub وتشغيل workflow أول مرة. لا تشارك بيانات تسجيل الدخول أو رموز التحقق مع أي شخص.
